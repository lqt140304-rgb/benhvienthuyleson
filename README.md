# Bệnh viện thú y Lê Sơn – website

Web tĩnh dựng bằng Jekyll, đặt trên GitHub Pages. Nội dung sửa qua Pages CMS (`.pages.yml`), form đặt lịch gửi tới Google Apps Script (`apps-script/Code.gs`).

- `_data/` – thông tin liên hệ, dịch vụ và bảng giá, bác sĩ
- `_posts/` – bài tư vấn
- `assets/` – CSS, JS, ảnh

Hướng dẫn vận hành: xem `HUONG-DAN.md`.
